# Duelul din Farfurie - Jocuri

Doua jocuri didactice despre alimentatie:

- `sortare.html`: Sanatos sau nesanatos? (drag and drop)
- `rebus.html`: Rebus cu ghicitori despre fructe si legume
- `index.html`: pagina de start cu linkuri catre ambele jocuri

## Publicare pe GitHub Pages
1. Incarca toate fisierele din acest folder in repository (Add file > Upload files).
2. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
3. Dupa cateva minute site-ul apare la `https://NUME.github.io/NUME-REPO/`.
